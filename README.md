# 无线电干扰源的快速自动定位与清除

2026 全国大学生数学建模竞赛 B 题参赛代码与论文。

## 题目概述

针对无线电干扰源的自动定位与清除问题，建立测向交会定位模型，设计机器狗自动搜索、定位、清除干扰源的整套算法。

- **问题1**：多边形定位区域直径的计算算法（半平面裁剪 + 旋转卡壳）
- **问题2**：第二检测点的选择策略（位置误差最小化）
- **问题3**：全向干扰源的搜索定位与清除（三阶段分级搜索）
- **问题4**：含定向干扰源的搜索定位与清除（四方向第二检测点 + 三圈密集环形搜索 + 边界月牙盲区模型）

## 运行方式

```bash

python robot_dog.py p3 <队号>

# 问题4（含定向干扰源场景）
python robot_dog.py p4 <队号>
```

队号通过命令行参数传入，未写死在代码中。
